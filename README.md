1. *Instal Python dan library yang diperlukan*:
```
bash
pkg install python
pip install requests colorama prettytable
```

2. *Simpan kode dalam file*:
Simpan kode tersebut dalam file dengan ekstensi `.py`, misalnya `zefoy.py`.

3. *Jalankan kode*:
```
bash
python zefoy.py
```

Pastikan Anda memiliki akses internet yang stabil dan telah memenuhi semua persyaratan yang diperlukan untuk menjalankan kode tersebut. Jika Anda mengalami masalah, pastikan Anda telah menginstal semua library yang diperlukan dan kode tersebut tidak memiliki kesalahan sintaks.
